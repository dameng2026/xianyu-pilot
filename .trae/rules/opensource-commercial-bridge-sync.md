# 商业桥接凭据配置

商业桥接为可选功能。地址、访问令牌与前台地址由部署方通过环境变量配置。
访问令牌支持 COMMERCIAL_BACKEND_ACCESS_TOKEN_FILE；禁止将明文或可逆编码的令牌写入仓库。
用户于 2026-10-28（北京时间）确认历史内置共享令牌已在服务端撤销或轮换；对应的三条精确历史指纹已记录到 .gitleaksignore。
保持 Gitleaks 全历史扫描；新提交、新位置或其他未处置凭据仍须阻断。
撤销或轮换应由商业服务管理员在服务端完成，不能仅靠删除当前源码解决。
生产环境的地址和凭据必须经过 Settings 校验，不允许在校验后注入默认凭据或 HTTP 地址。
